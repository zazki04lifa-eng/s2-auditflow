🚀 CARA MENGGUNAKAN:

1. Buka aplikasi AuditFlow
2. Klik "New Project" di menu atau dashboard
3. Scroll ke bagian "Muat Studi Kasus" (📚 section)
4. Klik card studi kasus yang ingin digunakan
5. Sistem akan otomatis:
   - Membuat project baru dengan data studi kasus
   - Mengisi narasi proses bisnis lengkap
   - Mengarahkan ke Audit Planning workspace
6. Dari sini kamu bisa:
   - Generate flowchart otomatis
   - Melakukan analisis risiko
   - Membuat dokumen audit

📝 DATA YANG SUDAH DIISI:

Setiap studi kasus sudah memiliki:

✓ Narasi lengkap proses bisnis (5-7 halaman)
✓ Profil perusahaan
✓ Sumber risiko utama (Key Risks)
✓ Tahapan proses detail
✓ Framework audit: COSO
✓ Area audit spesifik
✓ Metadata perusahaan

Dengan data ini, sistem dapat:
- Generate flowchart yang akurat
- Mengidentifikasi risiko WCGW
- Membuat audit program
- Membuat internal control assessment
- Generate working paper draft
